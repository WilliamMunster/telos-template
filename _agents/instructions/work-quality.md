# Work Quality Standards

- **Self-Improvement**: 被用户纠正后，立即更新 `_telos/lessons.md`，记录根因和避免方法
- **Verification First**: 完成任务前必须验证（测试通过、日志检查、功能演示），不能只是"看起来完成了"
- **Autonomous Debugging**: 看到错误/失败测试/日志异常时，直接分析根因并修复，不要等用户指导
- **Minimal Impact**: 只改必要的代码，避免引入新 bug 或过度设计
- **Root Cause Analysis**: 找根因，不做临时修复，符合 senior developer 标准
